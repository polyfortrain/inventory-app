# 要求分析書

## 1. 背景と目的

小規模な部材保管業務を想定する。在庫情報を手作業で管理する場合、一覧の確認や登録情報の訂正に手間がかかる可能性がある。

そのため、Webブラウザから在庫情報を閲覧・登録・更新・削除できる在庫管理アプリケーションを開発する。

## 2. 想定利用者と利用環境

- **利用者：** 在庫管理担当者
- **利用環境：** 学習用PC上のWebブラウザから、ローカル環境で利用する。

## 3. 利用者の要求

| 要求ID | 要求内容 |
|---|---|
| UR-01 | 登録済みの在庫情報を一覧で確認したい |
| UR-02 | 新しい在庫情報を登録したい |
| UR-03 | 登録済みの在庫情報を更新したい |
| UR-04 | 不要な在庫情報を削除したい |
| UR-05 | 在庫情報の変更結果を保存したい |

## 4. 対象範囲

**対象：** 在庫一覧・登録・更新・削除のCRUD4機能とデータの保存。

**対象外：** ログイン、入出庫履歴、検索、インターネット上での一般公開など。

なお、各機能の詳細な仕様や入力条件は要件定義で決定する。
