# 要件定義書

在庫管理担当者が、Webブラウザから在庫の一覧・登録・更新・削除を行える学習用アプリを作成する。正式版は **v1.0.0** とする。

参照：[要求分析書](requirements-analysis.md)

## 1. 管理する情報

| 項目 | 要件 |
|---|---|
| 在庫ID | 自動採番。利用者は変更できない。 |
| 在庫名 | 必須。1〜100文字。 |
| 数量 | 必須。0〜999,999の整数。 |

## 2. 機能要件

| ID | 対応UR | 機能 | 要件 |
|---|---|---|---|
| FR-01 | UR-01 | 一覧表示 | 保存済みの在庫ID・在庫名・数量を表示する。0件の場合も表示できる。 |
| FR-02 | UR-02 | 登録 | 在庫名と数量を入力し、新しい在庫を保存できる。 |
| FR-03 | UR-03 | 更新 | 指定した在庫の名称・数量を変更できる。 |
| FR-04 | UR-04、UR-07 | 削除 | 指定した在庫を、確認後に削除できる。 |
| FR-05 | UR-02、UR-03、UR-04、UR-05 | 入力チェック | 空欄・不正な数量・存在しないIDはエラーを表示し、データを変更しない。 |
| FR-06 | UR-06 | データ保存 | 登録・更新・削除の結果が、画面を再表示しても反映される。 |

## 3. 非機能要件・制約

- **開発環境：** これまでに学習したJava、PostgreSQLを使用する。
- **利用環境：** 学習用PCのローカル環境でWebブラウザから利用する。インターネット上には一般公開しない。
- **操作性：** 操作内容がわかりやすく、誤操作を防止できる画面とする。
- **対象外：** ログイン、検索、入出庫履歴などは実装しない。
